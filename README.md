# One-Line Office Joke: 24-Hour Sprint

One line (97 characters): my lunch break now has a waitlist, and the waitlist has a weekly meeting to discuss the waitlist.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
